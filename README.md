# Anime Otaku Yerevan: демо магазина + лендинг-история

Статический сайт без сборки (хеш-роутер), три языка (hy / ru / en): `index.html`, `css/style.css`, `js/app.js`, `js/i18n.js`, `data/products.json`, `img/`.
Локально: `python -m http.server 8790` и http://localhost:8790.

- Главная рассказывает историю аниме (5 глав: что это, как стало мировым, цифры, почему важно, магазин) и ведёт в каталог.
- Каталог: 12 товаров из публичного Instagram магазина (@animeotakuarmenia) + 3 стикерпака-примера из другого магазина (@stickershop.rnd), помечены «Пример», фон вырезан.
- Цены магазин не публикует: везде «Цена по запросу», корзина уходит одним сообщением в WhatsApp (+374 98 281910 — телефон магазина, проверить, что это WhatsApp).
- `python tools/build_catalog.py` пересобирает фото и `data/products.json` из `_raw/` (исходные кадры не хранятся в репозитории).
- Армянский текст — черновик, нужна вычитка носителем. Названия, помеченные `check: true`, подтвердить у магазина.
- Факты на главной: AJA (2023), Guinness World Records, Academy Awards.
